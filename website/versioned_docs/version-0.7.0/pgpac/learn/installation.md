## Homebrew

Published releases are distributed through `magnusopera/homebrew-tap`.

```bash
brew tap magnusopera/tap
brew install pgpac
```

## GitHub Releases

Each tagged release publishes zip archives for:

- macOS arm64
- Linux x64
- Linux arm64

Download the pgpac archive for your platform from [Starpac releases](https://github.com/MagnusOpera/starpac/releases), extract it, and place `pgpac` on your `PATH`.

## Verify the install

```bash
pgpac --version
```
